## 🧩 About

**Monster Hunter Wilds Overlay** is a comprehensive PC overlay for Monster Hunter Wilds featuring a monster HP bar, wirebug cooldown tracker, DPS meter, item box quick access, quest info panel, and a configurable in-game menu.

Based on popular tools like **MHW Overlay**, **HunterPie**, and **SmartHunter**.

---

## ✨ Features

### 🎮 Core HUD
- Monster HP Display — track remaining health in real time
- Wirebug Cooldown Tracker — monitor wirebug charges and timers
- DPS Meter — per-player and party damage breakdown
- Quest Info Panel — objectives, timers, and cart count
- Part Breaker Alerts — highlight broken and severable parts

### 🎨 UI & Overlay
- Custom Themes — color palettes and layout presets
- Resizable Panels — drag and snap any HUD element
- Click-Through Mode — overlay ignores mouse input when idle
- Multi-Monitor Support — pin HUD to a secondary display

### 🏋️ Utility & QoL
- Item Box Quick Access — one-key loadout and pouch view
- Session Logger — export hunt stats to CSV
- Hotkey Profiles — swap between quest and town layouts
- Auto-Hide in Menus — fade HUD during cutscenes and menus
